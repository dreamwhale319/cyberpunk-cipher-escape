# 사이버 암호 탈출

학생들이 다운로드해서 바로 실행할 수 있는 사이버펑크 스타일 암호 퍼즐입니다.

## 다운로드 방법

1. 아래 파일 링크를 엽니다.
2. 오른쪽 위의 `Download raw file` 버튼을 누릅니다.
3. 내려받은 `index.html` 파일을 더블클릭해서 브라우저로 실행합니다.

파일 링크: https://github.com/dreamwhale319/cyberpunk-cipher-escape/blob/main/index.html

## 바로 실행

GitHub Pages를 켜면 아래 주소로 바로 실행할 수 있습니다.

https://dreamwhale319.github.io/cyberpunk-cipher-escape/

GitHub Pages 설정 방법:

1. 저장소의 `Settings`로 이동합니다.
2. 왼쪽 메뉴에서 `Pages`를 선택합니다.
3. `Build and deployment`에서 Source를 `Deploy from a branch`로 둡니다.
4. Branch를 `main`, 폴더를 `/root`로 선택하고 저장합니다.
5. 잠시 뒤 위 실행 링크가 열립니다.
